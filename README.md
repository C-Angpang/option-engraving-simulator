# 옵션 각인 시뮬레이터

던전앤파이터 클래식 기획 과제용 골드 소비 시뮬레이터입니다.

- HTML/CSS/JavaScript만으로 실행되는 정적 페이지입니다.
- 경제 결과는 기획서의 가정에 따른 예측이며 실제 이용자 통계가 아닙니다.
- 기본 시나리오: 100,000명, 84일, 초기 보유량 30일분, 매일 수급의 50%를 각인 예산에 추가.
- 목표 비용 계산, 경제 효과 분석, 직접 각인 체험을 제공합니다.
